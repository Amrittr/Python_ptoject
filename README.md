# AI Impact on Student Life: Data Analysis

Python analysis of how AI tools affect student life, using the `AI_Impact_Student_Life_2026.csv` dataset. The script cleans the data and draws charts such as AI tool usage.

## Files

- `code.py`: analysis and charts (pandas, matplotlib, seaborn)
- `AI_Impact_Student_Life_2026.csv`: dataset
- `AI_Impact_Student_Life_Python_Report_Amrit_TR-compressed.pdf`: the written report

## Run

```bash
pip install pandas matplotlib seaborn
python code.py
```
